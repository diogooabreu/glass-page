### Estudo!
Esse projeto foi desenvolvido pra estudo e recapitulação de assuntos relacionados a HTML, CSS e JS.

## Objetivos
Os principais objetivos são:
- Revisão geral
- Compreensão da arquitetura de sites e páginas html (no que se relaciona com a estrutura hierarquica do html)
- Revisão de conceitos de CSS

### Conteúdos visualizados
**Tags e sestrutura do html:**
As principais tags revistas foram:
- header
- nav, com o uso de ul e li
- section
- table, com uso de tr e td
- aside
- figure e figurecaption
- article
- footer
 
**CSS**
- Estilização de imagens
- hover
- estilização geral com o uso de id e class
